Окно разделено на четыре основные зоны:

text

├────────────────────────────────┬─────────────────────────────────────┤
│                                │                                     │
│         ПРЕВЬЮ                 │      ПОЛОЖИТЕЛЬНЫЙ ПРОМПТ           │
│      ИЗОБРАЖЕНИЯ               │      ────────────────────           │
│                                │                                     │
│                                │      НЕГАТИВНЫЙ ПРОМПТ              │
│   Разрешение: 1024×1408        │      ────────────────────           │

Верхняя панель
Элемент	Назначение
📁 Открыть	Диалог выбора файлов (Ctrl+O)
📦 Пакетная обработка	Открыть окно batch-обработки (Ctrl+B)
💾 Экспорт	Экспорт метаданных текущего файла в TXT/JSON (Ctrl+S)
Шрифт	Выпадающий список шрифтов (сверху — часто используемые ⭐)
Размер	Размер шрифта в текстовых полях (8–48 pt)
Плитки	Слайдер размера миниатюр (80–320 px)
Drop-зона	Область для перетаскивания файлов/папок
Левая панель — Превью
Изображение сохраняет пропорции (не растягивается).

Под превью — строка с разрешением, форматом и размером файла.

Центральная панель — Промпты
Три поля, каждое со своей панелью инструментов:

Поле	Что содержит
ПОЛОЖИТЕЛЬНЫЙ ПРОМПТ	Основной prompt
НЕГАТИВНЫЙ ПРОМПТ	Negative prompt
ПАРАМЕТРЫ ГЕНЕРАЦИИ	Steps, Sampler, CFG scale, Seed, Model и т.д.
Правая панель — История
До 500 слотов, каждый пронумерован #1, #2, …

Первый загруженный файл остаётся #1, пока вы сами не перетащите его.

× появляется при наведении мыши (правый верхний угол карточки).

✓ показывает выделенные (правый нижний угол).

3. Загрузка изображений
Способ 1: Кнопка «📁 Открыть»
Нажмите кнопку 📁 Открыть (или Ctrl+O).

Выберите один или несколько файлов.

Первый файл сразу загрузится в редактор, все остальные добавятся в историю.

Способ 2: Перетаскивание (Drag & Drop)
Откройте Проводник / файловый менеджер.

Перетащите файлы или целые папки в область с надписью «Перетащите сюда изображение или папку».

Все найденные изображения (включая подпапки) добавятся в историю.

Способ 3: Через пакетную обработку
Если файлов много — используйте кнопку 📦 Пакетная обработка (см. раздел 7).

4. Просмотр и редактирование промптов
Автоматическое распознавание
При открытии файла приложение автоматически:

Читает метаданные (PNG tEXt/iTXt, JPEG EXIF, WEBP EXIF, ComfyUI JSON).

Декодирует многоязычный текст (UTF-8, UTF-16LE/BE, GBK, EUC-KR, Shift-JIS, CP1251 и др.).

Разделяет данные на три поля: промпт, негативный промпт, параметры.

Если ничего не найдено — показывает сообщение «В данном изображении метаданные генерации затерты или не распознаны».

Редактирование
Все три поля полностью редактируемые:

Меняйте текст прямо в окне.

Нажмите 💾 (иконка дискеты) рядом с полем — сохранит все три поля обратно в файл.

Нажмите 📄 (иконка копирования) — скопирует содержимое поля в буфер обмена.

После сохранения иконки дискеты загораются зелёным на 1.2 секунды — это подтверждение.

Кнопка «📄 Одним абзацем»
На панели положительного промпта есть кнопка 📄 Одним абзацем. Она:

Убирает все переносы строк.

Заменяет множественные пробелы/запятые на одинарные.

Превращает текст в один сплошной абзац.

Удобно, когда промпт «разбит» по строкам, а нужно вставить его в одно поле.

Статистика
Слева от иконок сохранения — счётчик:

text
Слов: 42 | Символов: 358
Обновляется в реальном времени.

5. Работа с историей (500 слотов)
Нумерация
Первый загруженный файл → #1.

Каждый следующий уникальный файл → #2, #3, … #500.

Файл, который уже в истории, повторно не добавляется.

Клик по миниатюре
Обычный клик — открывает файл в редакторе, сбрасывает все прежние выделения.

Ctrl + клик — переключает выделение (можно набрать несколько).

Shift + клик — выделяет диапазон от предыдущего клика до текущего.

Удаление из истории
Наведите мышь на карточку → появится × в правом верхнем углу. Нажмите её, чтобы убрать только из истории (файл на диске не удаляется).

Перетаскивание внутри истории (reorder)
Зажмите миниатюру и потяните на другую карточку:

Пример: тянем #1 на #5 → #1 становится #5, а бывшие #2..#5 сдвигаются на один вверх.

Остальные (выше #5) остаются на месте.

Очистка истории
Кнопка «Очистить все» в правом верхнем углу панели истории. История очищается полностью, но файлы на диске остаются.

Автосохранение
История сохраняется между запусками приложения автоматически. Все пути хранятся в системном реестре (Windows) или ~/.config/ (Linux/macOS).

6. Мульти-выделение и пакетный экспорт
Как выделить несколько миниатюр
Ctrl + клик — добавить/убрать одну карточку.

Shift + клик — выделить диапазон.

Выделенные карточки получают синюю рамку и галочку ✓.

Кнопка «💾 Сохранить выделенные»
Экспортирует положительные промпты всех выделенных миниатюр в один .txt файл.

Каждая подсказка — один абзац (переносы строк удаляются).

Подсказки разделены пустой строкой (\n\n).

Пример результата (файл selected_prompts.txt):

text
Wide establishing shot of a vast construction site where two women are the only saturated elements...

深海沉没宫廷的梦幻场景中，一位深肤色的高挑精灵女性站在中央...

portrait of a female spy in tight leather, cinematic lighting, 8k
Если ничего не выделено — кнопка берёт все файлы из истории (по очереди).

Если ни у одного файла нет промпта — появится уведомление в строке статуса.

7. Пакетная обработка (Batch Processing)
Открывается через 📦 Пакетная обработка (Ctrl+B).

Загрузка файлов
📄 Выбрать файлы — вручную отметить файлы.

📁 Выбрать папку — выбрать директорию с изображениями.

Чекбокс «Включая подпапки» — обходить рекурсивно.

Таблица результатов
Для каждого файла показывается:

Колонка	Что содержит
№	Порядковый номер
Имя файла	Имя (при наведении — полный путь)
Метаданные	✅ Найдено / ❌ Нет
Разрешение	Например, 1024x1408
Seed	Значение seed
Model	Название модели
Промпт (фрагмент)	Первые 120 символов
Двойной клик по строке → файл откроется в главном редакторе.

Пакетные операции
Кнопка	Что делает
📊 Экспорт в CSV / JSON	Сохраняет всю таблицу в CSV или JSON
📝 Экспорт TXT для всех	Создаёт отдельный .txt с промптом для каждого файла
🛡️ Очистить метаданные	Создаёт чистые копии без скрытых промптов (в отдельной папке)
🔍 Открыть в редакторе	Открывает выделенный файл в главном окне
CSV / JSON содержит
Filename, File Path, Has Metadata

Prompt, Negative Prompt

Steps, Sampler, CFG scale, Seed, Model

Width, Height

JSON — с полной структурой, включая parsed_params.

Очистка метаданных
Копирует изображения без скрытых промптов (имя получает префикс clean_). Полезно для публикации работ без утечки промптов.

Экспорт TXT для всех
Для каждого файла создаётся имя_файла.txt с положительным промптом. Если два файла имеют одинаковое имя — добавляется суффикс _1, _2 и т.д.

Прогресс-бар
Внизу таблицы — индикатор прогресса. Отмена через Esc.

8. Drag & Drop
Перетаскивание из истории во внешние приложения
Просто схватите миниатюру и потяните:

Куда	Что произойдёт
Рабочий стол	Копия файла сохранится на рабочий стол
Открытая папка Проводника	Файл скопируется туда
Photoshop / GIMP / Krita	Изображение откроется в редакторе
Telegram / Discord / Slack	Изображение отправится в чат
Браузер (поле загрузки)	Файл подхватится для загрузки
Терминал / текстовый редактор	Вставится путь строкой
Порог срабатывания
Драг начинается после смещения мыши на 6 пикселей. Быстрое лёгкое движение не считается драгом — это клик.

Перетаскивание внутрь приложения
Из Проводника или с рабочего стола → перетащите на drop-зону сверху. Все изображения из папок (включая подпапки) добавятся в историю.

Кнопка 💾 Экспорт (Ctrl+S):

13. Многоязычная поддержка
Приложение корректно работает с промптами, содержащими:

Английский — базовый язык SD

Русский — кириллица (Windows-1251, UTF-8)

Китайский — упрощённый (GBK) и традиционный (Big5)

Японский — Kanji, Hiragana, Katakana

Корейский — Hangul

Арабский, иврит — RTL-языки

Смешанные промпты — например, «portrait of a girl, 深海のシーン, детализация high»

Если промпт содержит смесь языков (что часто бывает в SDXL/Neo моделях) — весь текст отобразится корректно.

14. Решение проблем
14.1. «Метаданные генерации не найдены», хотя они есть
Возможные причины:

Файл был очищен (кем-то удалены метаданные).

Нестандартный формат — например, кастомная реализация сохранения.

Повреждённый EXIF — можно проверить через ExifTool или аналоги.

Что делать:

Проверьте, что файл читается другим инструментом (например, SD Prompt Reader).

Если он тоже показывает пустоту — метаданных нет.

Если он показывает промпт, а Tip Editor — нет, сообщите об этом разработчику с указанием формата (PNG/JPEG/WEBP).

14.2. Краказябры вместо текста
Причина: старые версии (до 9.3) некорректно декодировали бинарный EXIF-блоб.

Решение: обновитесь до v9.5 — там правильная обработка UTF-16, latin-1 и многоязычного текста.

14.3. Мусор в начале промпта (䕸楦䵍*)
Причина: бинарный EXIF-блоб декодировался как UTF-16.

Решение: v9.5 ищет маркер UNICODE\0 внутри блоба и читает текст только после него.

14.4. Кнопка «×» съезжает или не появляется
Причина: QSS text-align и разные шрифты.

Решение: начиная с v9.5 символ рисуется вручную через QPainter — всегда точно по центру.

14.5. Тормозит при перетаскивании
Причина: парсинг метаданных блокирует UI на клике.

Решение: с v9.5 клик обрабатывается на mouseRelease, а не на mousePress, и драг начинается с 6 px.
